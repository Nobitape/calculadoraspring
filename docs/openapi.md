# 🔍 Consola Interactiva (Swagger UI)

A continuación se muestra la consola interactiva de **Swagger UI** cargada dinámicamente desde la especificación **OpenAPI 3.1.1** de la aplicación backend.

> [!TIP]
> Puedes utilizar el botón **"Try it out"** en cada método para realizar peticiones HTTP de prueba directamente a tu servidor local.

> [!IMPORTANT]
> Para interactuar y probar el endpoint `/calcular`, asegúrate de tener la aplicación Spring Boot corriendo localmente en `http://localhost:8080` (ejecutando `./mvnw spring-boot:run`).
